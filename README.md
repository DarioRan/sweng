# A Vision-Grounded Repair Assistant

You photograph a bicycle component and ask a question in your own words. A
detector names the part in the photo, the answer is composed only from passages
retrieved out of indexed Shimano dealer's manuals, and every step carries a
citation to document, page and figure. When retrieval confidence is too low the
system says the answer is not in the manuals instead of calling the model, and
any step the manuals mark professional-only stops the procedure.
